# CONTROLPLANE SDK Specifications

## Supported SDKs

1. **JavaScript SDK (`@controlplane/sdk`)**: Browser and web applications.
2. **Node.js SDK (`@controlplane/node`)**: Backend services, microservices, and server-side runtimes.
3. **Flutter SDK (`controlplane_flutter`)**: Cross-platform mobile applications.

## Evaluation Guarantee

All SDKs share identical evaluation results when supplied with the same configuration snapshot and evaluation context.
